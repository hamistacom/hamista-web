# پیش‌نمایش قالب hamista

پیش‌نمایش اولیه‌ی صفحه‌ی اصلی قبل از ساخت قالب المنتور. ساختار و حس موشن از سایت مرجع گرفته شده و با دیزاین‌سیستم «Minimalist Modern» ترکیب شده است. صفحه فارسی و راست‌چین است.

## فایل‌ها

| مسیر | توضیح |
|---|---|
| `dist/hamista-preview.html` | نسخه‌ی تک‌فایل. فونت‌ها داخل خود فایل هستند و صفحه بدون اینترنت و بدون Google Fonts هم کار می‌کند. |
| `index.html` + `fonts/` | سورس صفحه |
| `build.mjs` | ساخت دوباره‌ی نسخه‌ی تک‌فایل با دستور `node build.mjs` |
| `screenshots/` | تصویر کلی (`00-overview.jpg`)، تصاویر تمام‌صفحه‌ی دسکتاپ در چهار ترکیب رنگ و تم، و دو تصویر موبایل |

پارامترهای آدرس برای مرور سریع:
- `?theme=light` یا `?theme=dark`
- `?accent=blue` یا `?accent=amber`

دکمه‌ی خورشید و ماه در هدر تم را عوض می‌کند. انتخاب رنگ پایین صفحه فقط برای این پیش‌نمایش است و در قالب نهایی وجود ندارد.

## چیزهایی که در پیش‌نمایش هست

- **حالت روشن و تیره**: همه‌ی رنگ‌ها از متغیرهای CSS خوانده می‌شوند. اگر کاربر قبلاً تمی انتخاب نکرده باشد، تم سیستم‌عامل او اعمال می‌شود و انتخابش ذخیره می‌ماند.
- **اسکرول نرم**: پیاده‌سازی شبیه Lenis و بدون کتابخانه‌ی خارجی. روی موبایل و برای کسانی که «کاهش حرکت» را روشن کرده‌اند، اسکرول بومی مرورگر استفاده می‌شود.
- **داستان اسکرول‌محور «جرقه»**: یک بخش پین‌شده که با اسکرول، جرقه مسیرش را می‌کشد و چهار مرحله را روشن می‌کند. هم‌زمان رنگ پس‌زمینه عوض می‌شود.
- **موشن‌های دیگر**:
  - ورود نرم المان‌ها با تأخیر پلکانی
  - تیتر هیرو که کلمه‌به‌کلمه ظاهر می‌شود
  - شمارنده‌ها با اعداد فارسی
  - نمودارهایی که هنگام دیده‌شدن رسم می‌شوند
  - پارالاکس هیرو با حرکت ماوس
  - نور زیر نشانگر روی کارت‌ها
  - تب‌های خودچرخان
  - آکاردئون
  - دموی دستیار هوشمند
- **فونت‌ها**: Markazi Text برای تیترها (نقش «سریف گرم» در دیزاین‌سیستم)، Vazirmatn برای متن، و JetBrains Mono برای برچسب‌ها. هر سه با مجوز OFL هستند و روی خود سایت میزبانی می‌شوند.

## نقشه‌ی تبدیل به المنتور

| بخش | ساختار در المنتور |
|---|---|
| هدر و فوتر | Theme Builder (هدر چسبان که بعد از اسکرول شیشه‌ای می‌شود) |
| هیرو | Container + Heading + Text + Button×2 + HTML (گرافیک) |
| آمار | Container تیره + Counter×4 + نوار متحرک |
| مسیرها | Tabs با استایل سفارشی |
| سه قدم | Icon Box×3 |
| داستان جرقه | Container با ارتفاع 420vh + HTML + `hm-motion.js` |
| محصولات | Bento با Inner Container + نمودارهای HTML |
| دستیار | HTML (بعداً به API هوش مصنوعی وصل می‌شود) |
| سؤالات | Accordion |
| CTA نهایی | Container تیره + Form |

رنگ‌ها و فونت‌ها در Global Colors و Global Fonts المنتور تعریف می‌شوند. موشن‌ها به‌صورت کلاس‌های CSS (مثل `hm-reveal`) روی ویجت‌ها اعمال می‌شوند.
