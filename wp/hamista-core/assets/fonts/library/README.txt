Hamista font library
====================

Commercial Persian fonts used under the site owner's licences:
IRANYekan, IRANSansX, Peyda, Doran, Ravagh, Lahzeh, Modam, Hamrah and
Gramophone (fontiran.com), and Pinar (fontamin.com).

Each licence covers the sites it was bought for. Before delivering Hamista to
another site or person, check that the licence allows it, or remove the
folders of the families that it does not cover: the font menus simply stop
offering them and the theme falls back to Vazirmatn.

Files are the originals converted to woff2 where needed; outlines, names and
licence fields are unchanged. To refresh them, run
    python3 tools/fonts/library.py <folder-with-the-original-files>
